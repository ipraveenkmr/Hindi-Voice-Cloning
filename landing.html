Installation & Setup Guide

Follow these professional steps to set up your local environment for Open Source AI Hindi Voice Cloning.

1

Prerequisites

Install Python 3.10 and **Microsoft C++ Build Tools**. Ensure you select "Desktop development with C++" during installation to avoid compilation errors.

winget install Python.Python.3.10
2

Environment Setup

Create a dedicated virtual environment and install the required AI modules including `TTS` and `torch`.

py -3.10 -m venv env
.\env\Scripts\activate
pip install -r requirements.txt
3

Launch the GUI

Start the CodingMSTR modern dashboard, paste your Hindi script, upload your voice sample, and click "Start Cloning".

python app.py

⚠️ Common Installation Fix (MSVC Error)

If you encounter a "Microsoft Visual C++ 14.0 or greater is required" error, download the Build Tools from the visual studio website and ensure you check the MSVC v143 and Windows 10/11 SDK boxes. This is essential for building the TTS engine's core C++ extensions.
